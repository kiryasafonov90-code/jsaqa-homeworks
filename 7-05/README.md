# Домашнее задание 7.5 — Puppeteer 2

Автотесты бронирования билетов в учебном приложении «Идём в кино».

## Установка

Требуется Node.js 20 или новее.

~~~bash
cd 7-05
npm install
npx puppeteer browsers install chrome
~~~

По умолчанию используется учебный стенд http://qamid.tmweb.ru/client/index.php.
Адрес стенда можно изменить через переменную окружения BASE_URL.

## Задание 1 — Puppeteer

Запуск: npm test

Три теста:
1. Happy path: выбрать одно свободное место и проверить предварительный билет.
2. Happy path: выбрать два свободных места и проверить предварительный билет.
3. Sad path: не выбирать места и проверить, что кнопка бронирования неактивна.

Для тестов используются beforeEach / afterEach, Page Object и общие команды.

## Задание 2 — Puppeteer + Cucumber

Запуск: npm run test:bdd

Те же три сценария описаны в features/booking.feature.
Шаги находятся в features/step-definitions/booking.steps.js,
хуки браузера — в features/support/hooks.js.

## Проверка

Оба набора: npm run test:all

Оба набора с видимым браузером: npm run test:headed

Сопоставление шагов Cucumber без запуска браузера: npm run test:bdd:dry-run

В тестах используется день 2 и сеанс 1. При изменении расписания эти значения можно поменять в константах DAY и SESSION файла tests/booking.test.js и в Предыстории файла features/booking.feature.

## Исправление замечаний

Метод openSession(day, session) открывает расписание один раз, выбирает день и затем заново получает элементы сеансов из текущего DOM. Перезагрузок внутри циклов и повторного использования устаревших ElementHandle нет.

После клика по нужному сеансу метод сразу ждёт схему зала и возвращает управление тесту. Следующий шаг выбирает кресла уже на открытой схеме.

Тесты останавливаются на предварительном подтверждении и не получают код бронирования.
